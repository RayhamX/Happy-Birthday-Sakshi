# Happy Birthday — Sakshi

Simple PWA: "Two Worlds, One Birthday" — a small birthday site for Sakshi.

Files included:
- index.html
- manifest.json
- sw.js
- assets/README.md (list of expected images/icons)

Quick start (local):
- Add the images into the `assets/` folder as named in assets/README.md.
- Run a local static server, for example:

  python -m http.server 8000

- Open http://localhost:8000

Deploy:
- Push this repo to GitHub (already created) and enable Pages, or host on any static host.
